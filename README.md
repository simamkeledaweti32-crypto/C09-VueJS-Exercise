## Project Description
Food Fest Ticket Landing page for Cape Town Food Fest. This app displays ticket types in reusable Vue.js cards with title, price, benefits list, "Tickets left" counter, and "Reserve now" button with click event.

## Features
- Reusable ticket card components
- Ticket details: title, price, benefits list
- Live "Tickets left" counter
- Styled difficulty/availability indicators
- Reserve button with Vue click event
- Mobile responsive design

## How to Run
1. Clone repository
2. Run `npm install`
3. Run `npm run dev`
4. Open localhost URL
